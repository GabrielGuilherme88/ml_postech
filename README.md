# Datathon Fase 05

Repositório padrão para a competição do Datathon - Fase 05 (MLOps, LLMs e Agentes).

## Estrutura do projeto

- `data/`: Dados brutos, processados e golden set.
- `src/`: Código fonte.
- `tests/`: Testes em pytest.
- `evaluation/`: Scripts de avaliação (RAGAS, LLM-as-judge).
- `docs/`: Documentação e Cartões de Modelo.
- `configs/`: Configurações yaml.
